# Security Policy

## Supported Versions

We actively provide security updates for the following versions of Chit Chat:

| Version | Supported          |
| ------- | ------------------ |
| 12.0.x  | :white_check_mark: |
| < 12.0  | :x:                |

## Reporting a Vulnerability

We take the security of this project seriously. If you find a security vulnerability, please do **not** open a public issue. Instead, follow these steps:

1. **Email the Maintainer**: Send a detailed report to `[sawantviraj976@gmail.com]`. 
2. **Details to Include**:
   - Type of issue (e.g., XSS, SQL Injection, Data Leak).
   - Step-by-step instructions to reproduce the issue.
   - Any potential impact it might have on users.

### Our Response Process
- We will acknowledge receipt of your report within 48 hours.
- We will provide a timeline for a fix.
- Once fixed, we will push an update and provide credit to the researcher (if desired).

## Responsible Disclosure
To protect the community, we ask that you do not share information about a security vulnerability publicly until we have had the opportunity to address it.

## Third-Party Services
This project uses **Firebase** for authentication and database services. If you discover a vulnerability specifically related to Firebase infrastructure, please report it directly to the [Google Vulnerability Reward Program](https://www.google.com/about/appsecurity/reward-program/).
